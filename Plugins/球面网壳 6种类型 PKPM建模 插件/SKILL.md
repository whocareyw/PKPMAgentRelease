# 球面网壳建模（JGJ7-2010 六型）

在 PKPM 当前工程中生成 JGJ 7-2010 常用六种单层球面网壳之一：**肋环型、肋环斜杆型、
三向格子型、联方型、凯威特型（Kn 型）、短程线型**。底环/底边界支承于所在标准层的
层底（空白工程即 z=0），顶点在层底+矢高处。

## 参数与各类型的对应关系

| 类型 | 网格构成 | 使用的划分参数 |
| --- | --- | --- |
| 肋环型 | K 根径向肋 + 环向杆，梯形网格 | 扇区数 K、环带数 N |
| 肋环斜杆型 | 肋环型基础上每格 1 根斜杆（相邻格反向，锯齿对称） | K、N（K 取偶数更对称） |
| 三向格子型 | 三族平行线网格竖投影成等边三角形网格，底圆截断+封边 | 细分密度 n（杆长≈D/n） |
| 联方型 | 两族斜杆交叉成菱形网格（无肋无环，规程基本形式），底圆截断+封边 | n |
| 凯威特型 | K 扇区：径向肋+扇区脊线+环杆+V 形斜杆 | K、N |
| 短程线型 | 内接正二十面体细分 ν 次取球冠（20×ν² 面），底圆截断+封边 | n 作 ν 用（杆长≈1.05R/ν，建议 12~24） |

- **跨度 D / 矢高 f**：球冠的平面直径与顶点高度，单位 m。要求 0 < f ≤ D/2。
- **球面半径**：不设表单参数——与 D、f 联动（R=(D²/4+f²)/2f，恒 ≥ 半跨），脚本始终
  自动计算（如 D=100、f=15 时 R=90.83 m）。底环锚固于层底，实际矢高完成后打印。
- **扇区数 K / 径向环带数**：仅环系三类使用；三向/联方/短程线会打印"不使用"提示。
- **细分密度 n**：仅三向/联方/短程线使用，含义见上表。
- **钢管外径 / 壁厚**：全部杆件统一圆钢管截面，单位 mm。

## 类型相关行为差异（输出提示已覆盖）

- **底边界形状**：六种类型的底边界**均为精确圆形**，边界节点全部位于层底标高、
  半径 D/2 的底圆上。肋环/肋环斜杆/凯威特的底环即整圆（肋环系 K 个节点、凯威特 2K 个）；
  三向格子/联方 = 各网格线延伸至底圆交点后截断，短程线 = 跨切除面的棱按球面插值求底圆
  交点后截断，三者再沿圆周设环形封边杆闭合（边界节点数运行时打印），支座沿底环节点布置。
- **联方型**为纯菱形网格，平面外刚度较弱，规程精神下必要时可后续增设环向杆件或改选
  三角形网格形式（输出会提醒）。
- 单层网壳应采用刚接节点（JGJ 7-2010 第 3.1.8 条），MCP 建入的斜杆默认刚接，无需处理。

## 注意事项

- **可运行于已有构件的工程**：每次运行自动**新建一个标准层**（层号=已有最大层号+1），
  网壳整体生成在该层内，底环标高=该层层底（即既有建筑组装顶部标高），组装表追加新层，
  原有构件与组装不变。重复运行会叠出多个网壳层，无需的可自行删除。
- 运行前 PKPM 必须已打开目标工程，且不能停在弹窗上；建模完成后自动保存。
- **支座不会自动设置**（MCP 暂无支座接口）：请按上述底边界说明手动添加支座，单层网壳
  通常取三向固定铰支座。
- 荷载布置、启动计算、结果提取不在本插件范围内。

## 实现要点（改代码前必读）

- **几何与建模分离**：`scripts/geometry.py` 是纯数学模块（无 PKPM 依赖），按类型返回
  `nodes/members/boundary/descr`；`main.py` 只负责参数校验、PKPM 标准层操作与杆件
  落图。改几何只动 geometry.py，可脱离 PKPM 单测（节点须全落在 R 球面上、杆件表去重、
  网格连通）。
- **PKPM 流程**：先 GetFloorAssemTable 读组装表、GetStandFloorParams 探测已有标准层
  总数，确定新层号与底环标高（=组装顶部）；CreateOrModifyStandFloor 建空层。MCP 建
  斜杆时节点默认落在层顶，脚本先布置 500mm 临时短柱（柱顶=节点标高）把节点"栽"到球面
  位置，再建网壳杆件，最后删临时柱；期间把网壳层**底边界**临时下移 1000mm（新层与下层
  的交界，N=1 时即全楼底标高）以容纳底环处的临时柱，完成后恢复并**保留新层**于组装表。
- 校验时 GetOneStdFlrMember 对空/不存在层可能回退返回其它层构件，须按标高域过滤后再
  核对。节点标高按整毫米截断，球面偏差 ≤1mm。
- 三向/联方先按原始网格节点归线，再把每条线两端延伸至底圆交点（交点优先吸附 0.25 倍
  名义杆长内的既有节点到圆上）；短程线型全球细分后按 z≥底环标高切除，跨切面的棱用球面
  插值（slerp）求底圆交点（同样就近吸附，避免极短/零长杆）。底圆节点按角度排序、近距
  （<0.25 倍名义杆长）合并后环向封边，合并弃点压实移除；故六种类型底边界均为整圆。
- 短程线型有退化防护：球冠半顶角须大于二十面体首环纬度（63.43°/ν），即 ν > 63.43°/φ_max，
  否则球冠内仅含顶点、无法成壳，脚本直接报错提示（矢跨比过小时请增大矢高或改选类型）。
