# 插件分享

本目录分享社区与官方制作的 **PKPM Agent 插件** 及配套工具。

> 插件是 PKPM Agent 中"把一次成功对话制作成带**参数表单**的可复用任务"——填入跨度、截面等参数、点击 **RUN** 即可一键重复执行，详见仓库 README「插件 & 脚本系统」一节。

---

## 球面网壳 6 种类型建模（JGJ 7-2010）

在 PKPM / SAP2000 中一键生成《空间网格结构技术规程》JGJ 7-2010 六种常用单层球面网壳：**肋环型、肋环斜杆型、三向格子型、联方型、凯威特型（Kn 型）、短程线型**。填入跨度、矢高、网格划分与圆钢管截面参数即可建模，六种类型底边界均为精确圆形，球面半径由跨度 / 矢高自动导出。

| 目录 | 内容 |
| --- | --- |
| [球面网壳 6种类型 PKPM建模 插件](./球面网壳%206种类型%20PKPM建模%20插件) | PKPM Agent 插件：在 PKPM 当前工程自动新建标准层生成网壳并保存；支座需按说明手动设置 |
| [球面网壳 6种类型 SAP2000建模 插件](./球面网壳%206种类型%20SAP2000建模%20插件) | PKPM Agent 插件：连接 SAP2000 当前实例建模（可追加到既有模型），可选自动设置底环固定铰支座。另内含 `SAP2000球面网壳建模.exe` **独立程序**，不依赖 PKPM Agent、双击即可运行 |

两个插件的几何算法同源（`scripts/geometry.py` 纯数学模块）。参数说明、六种类型的网格构成与注意事项详见各目录下的 `SKILL.md`。
