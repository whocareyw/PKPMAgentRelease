# SAP2000 球面网壳建模（JGJ7-2010 六型）

在 SAP2000 当前实例中生成 JGJ 7-2010 常用六种单层球面网壳之一：**肋环型、肋环斜杆型、
三向格子型、联方型、凯威特型（Kn 型）、短程线型**。几何与 PKPM 版「球面网壳建模」插件
同源（`scripts/geometry.py` 纯数学模块），六种类型底边界**均为精确圆形**：边界节点全部
位于底圆（半径 D/2、标高 z_base）上并沿圆周环向封边闭合。

## 平台行为

- **连接**：优先连接已运行的 SAP2000 实例；无实例时才启动新实例。
- **新/既有模型**：当前模型为空（无节点无框架且未保存）时新建空白模型并设单位制
  **N_mm_C**；否则在既有模型中**追加**构件，不改动原有对象，并跟随既有模型单位制
  （按 eUnits 码自动把 mm 几何换算为 in/ft/mm/m/cm）。
- **杆件**：Frame 对象，SAP2000 框架默认**刚接**，符合单层网壳刚接节点要求
  （JGJ 7-2010 第 3.1.8 条），无需额外处理。
- **截面/材料**：Pipe 圆钢管截面 `PIPE<外径>x<壁厚>`；材料 `STEEL_SHELL`
  （E=206000MPa、ν=0.3，用 SetMaterial/SetMPIsotropic 定义，不依赖材料库）。
- **节点/杆件命名**：`SRN<运行标识>_i` / `SRM<运行标识>_k`（运行标识为时间戳）。
- **重新生成先删旧**：每次运行开头自动删除上次运行的建模内容（`SRM*` 杆件逐根删除后再删
  `SRN*` 节点）；连接了用户自有构件的节点删不掉时会保留并提示。故模型中始终只保留最近一次
  生成的网壳，也避免同坐标节点合并、重杆导致建杆失败。
- **支座**（可开关，默认开）：底环节点设三向平动固定铰（UX/UY/UZ 约束、转动自由）。
- **保存**：既有已保存模型直接 Save；新模型存到运行目录下 `SAP2000球面网壳/<类型>_D<f>.sdb`。
- **不运行分析**：仅建模，工况定义与计算由用户在 SAP2000 中自行完成。

## 参数与各类型的对应关系

| 类型 | 网格构成 | 使用的划分参数 |
| --- | --- | --- |
| 肋环型 | K 根径向肋 + 环向杆，梯形网格 | 扇区数 K、环带数 N |
| 肋环斜杆型 | 肋环型基础上每格 1 根斜杆（相邻格反向，锯齿对称） | K、N（K 取偶数更对称） |
| 三向格子型 | 三族平行线网格竖投影成等边三角形网格，底圆截断+封边 | 细分密度 n（杆长≈D/n） |
| 联方型 | 两族斜杆交叉成菱形网格（无肋无环，规程基本形式），底圆截断+封边 | n |
| 凯威特型 | K 扇区：径向肋+扇区脊线+环杆+V 形斜杆 | K、N |
| 短程线型 | 内接正二十面体细分 ν 次取球冠（20×ν² 面），底圆截断+封边 | n 作 ν 用（杆长≈1.05R/ν，建议 12~24） |

- **跨度 D / 矢高 f**：球冠平面直径与顶点高度，单位 m；要求 0 < f ≤ D/2。
- **球面半径**：导出量 R=(D²/4+f²)/2f，不设表单参数，脚本自动计算。
- **底环标高 z_base**：底圆相对模型原点的高度（m），默认 0；在既有模型顶部放壳时
  填既有模型顶部标高。
- **扇区数 K / 径向环带数**：仅环系三类使用；三向/联方/短程线会打印"不使用"提示。
- **细分密度 n**：仅三向/联方/短程线使用，含义见上表。

## 注意事项

- **重复运行**：不会叠加——每次运行先删除上次内容再重建；如需保留旧壳，请先在 SAP2000
  中改名（去掉 SRM/SRN 前缀）或另存模型。
- **短程线型退化防护**：球冠半顶角须大于二十面体首环纬度（63.43°/ν），即 ν > 63.43°/φ_max，
  矢跨比过小时脚本直接报错提示（增大矢高、减小跨度或改选类型）。
- **联方型**为纯菱形网格，平面外刚度较弱；必要时在 SAP2000 中后续增设环向杆件或改选
  三角形网格形式（三向格子/短程线）。
- 荷载布置、工况定义、启动计算、结果提取不在本插件范围内。

## 实现要点（改代码前必读）

- **几何与建模分离**：`scripts/geometry.py` 是纯数学模块（无软件依赖），按类型返回
  `nodes/members/boundary/descr`（单位 mm，底环锚固于 base）；改几何只动 geometry.py，
  可脱离 SAP2000 单测（节点须全落在 R 球面上、杆件表去重、底圆闭合）。
- **COM 规范**：comtypes 连接须先 `CoInitialize()`；`GetObject` 无实例返回 None 须判空；
  ByRef 出参占位 `' '`，返回元组末位才是状态码（`rc_of` 统一处理）；`SetPresentUnits`
  必须在 `NewBlank` 之后设置。
- **单位换算**：几何内部一律 mm，落模型前乘 `LEN_FACTOR[eUnits码]`；截面外径/壁厚同样换算。
- **建模顺序**：材料 → 截面 → 节点(AddCartesian，用户名 SRN*) → 杆件(AddByPoint，用户名
  SRM*，直接带截面) → 支座(SetRestraint) → 刷新视图 → 保存。
