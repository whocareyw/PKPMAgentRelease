## 1. 产品简介

**把工程需求说清楚，让智能体接着做。**

PKPM Agent 将资料查阅、专业软件操作和成果整理串联在同一段对话中。你可以让它查找规范条文、批量调整模型、提取分析结果，再把数据整理成计算书、表格或汇报材料；已经验证过的流程，还可以做成插件，留给下一个项目使用。

| 你要完成的工作 | PKPM Agent 可以怎样协助 |
| --- | --- |
| **查资料，核对依据** | 将规范、图集、软件手册和项目资料放入本地知识库，通过对话检索、解释与对比，点击回答中的出处回看原文 |
| **操作软件，推进设计** | 在 PKPM 及多款建模、分析、绘图软件中执行建模、改模、计算与结果提取，支持施工图识别校审和绿色低碳分析 |
| **整理数据，交付成果** | 把模型与计算结果整理为 Word、Excel、PPT、PDF，也可沿用已有模板编辑、排版或翻译 |
| **沉淀方法，重复使用** | 将成功对话或脚本做成带参数表单的插件，填入新项目的参数即可运行，常用方法也可保存为技能 |

### 2.5.2 值得关注的变化

- **让手边资料成为可追溯的知识库**：支持导入规范、图集与项目文件，按关键词或问题含义查找资料；回答中的出处可打开原文预览，PDF 支持定位页码与缩放。知识库还可放在网络共享目录，供同事复用。
- **PPT 从内容组织到视觉交付全面升级**：内置 **24 套设计体系与 7 类场景指南**，覆盖工程方案、工作汇报、学术答辩等用途；从逐页叙事、图表和配色，到模板沿用、版面检查与出图复核，形成完整制作流程。还可按参考风格设计、美化已有页面，或将图片、PDF 页面复刻为可编辑演示文稿。
- **Word 与 Excel 更贴近实际工作**：Word 可沿用原文档的样式、页眉页脚和编号，处理合并表格、三线表、公式、修订与整篇翻译；Excel 直接在目标工作簿中填写数据、公式与格式，修改过程在应用中可见，计算结果随输入变化而更新。
- **把重复工作做成自己的工程工具**：插件支持按选项显示相关参数，例如选择不同截面后只填写对应尺寸；通过「自定义界面」拖动参数和分组、调整宽度、修改说明文字，让工具更贴合自己的使用习惯。
- **从 AutoCAD 扩展到国产 CAD**：支持 AutoCAD、浩辰 CAD 和中望 CAD 的绘图、改图与信息提取。多款 CAD 同时运行时，可先明确目标产品，再继续操作。
- **项目文件就在对话旁**：工作空间面板可浏览文件、预览文本和图片、全屏查看成果；文件可拖入输入框或通过 `@` 引用，继续用于下一步任务。
- **长任务更容易接着做**：执行过程可折叠，完成后突出呈现成果；上下文用量可查看，接近上限时可手动压缩会话，完整消息仍保留。每轮回答还可查看本轮 Token 消耗，便于了解不同任务的用量。
- **工程能力进一步延伸**：覆盖 PKPM 图纸审查、STS 钢结构、JCCAD 基础（Beta），以及 Abaqus、Tekla Structures、SAUSG（Beta）、BIMBase 参数化组件和 PKPM 绿色低碳系列软件。
- **日常使用更顺手**：浅色、深色与跟随系统三种外观，窗口置顶、前进后退和窄窗口侧栏适配；启动、安装进度、连接与错误提示也同步优化。

下文介绍当前 2.5.2 的使用方式；各专业功能需安装对应软件，并具备相应授权。

## 2. 核心技术：从工程意图到可执行成果

工程任务往往同时涉及专业规则、软件接口、批量数据和成果文件。PKPM Agent 基于 **LangChain / LangGraph 深度定制工程执行框架**，围绕这些环节构建了自研的接口适配、技能管理、插件和任务执行机制。

### CodeReAct：以代码串起推理与行动

采用 **CodeReAct（推理—代码执行—反馈）** 的设计：智能体先读取相关专业指导、检索所需接口，再编写代码完成操作，并根据软件返回结果继续推进。循环、条件判断、数据处理和跨软件调用可以在一段脚本中组织起来，适用于批量修改构件、筛选计算结果、汇总报表等工程任务。中间数据留在会话的执行环境中，后续步骤可直接接着使用。

### 自研 MCP 编程调用适配器：让工程接口参与程序运算

基于标准 MCP 协议，自研 **PTC（Programmatic Tool Calling，编程式工具调用）适配器**，将服务提供的工具与数据结构映射为 Python 可调用接口。智能体可先按类别检索接口，再在代码中组合调用、处理返回数据，只将需要解释的关键结果带回对话。适配器支持同步与异步调用、超时和中断处理，为耗时计算与多步骤软件联动提供执行支撑。

### 专业技能与插件体系：把经验转化为可执行资产

**Skills** 将软件操作方法、参数约定和参考资料组织成可按需读取的专业指导；**插件**进一步将已验证的流程封装为参数表单与执行脚本。用户既可让 Agent 修改业务逻辑，也可自己调整表单布局。从一次对话到一件常用工具，建模方法、检查规则和数据处理流程都能持续积累与复用。

### 可追溯知识与上下文管理：兼顾依据与任务延续

知识库结合关键词与语义检索，保留资料章节和原文件页码，使回答能够连接到可核对的原文。长会话则通过**结构化摘要、近期消息和历史归档**管理模型上下文；压缩时保留完整消息，并保留已读取的技能指导，支持继续执行和回查历史细节。

### 独立执行与分级审批：让复杂任务可中断、可恢复

每个会话拥有独立的代码执行进程，变量和软件连接可跨步骤复用，脚本进程异常时可重新建立执行环境；停止操作会先尝试中断执行，必要时重建进程。配合 Ask / Auto / Full 三档审批方式，用户可按任务熟悉程度选择介入方式，详见[权限控制](#73-权限控制)。

## 3. 快速开始

### 3.1 环境要求

- 💻 **按需安装对应软件**（使用对应功能时需安装并可正常启动）：
  - PKPM 2027R1.0-64 及以上（含 STS、JCCAD、图纸审查、绿色低碳等模块）
  - AutoCAD（建议 2018 及以上）/ 浩辰 CAD / 中望 CAD，需支持 COM 自动化接口
  - SAP2000 / ETABS / STAAD.Pro / Rhino
  - Abaqus 2024 / 2025 / 2026、Tekla Structures 2020 ~ 2026、SAUSG
  - BIMBase / PlantS
  - Microsoft Office / WPS Office（用于表格实时操作、文档排版检查及成果预览）
- 🌐 **需连接网络**，用于大模型调用，以及按需使用的资料解析、语义检索等服务。
- 🔑 **授权按功能开放**：登录账号或使用锁码授权后，按已开通的产品使用相应能力；标注「需授权」的技能或接口需先开通对应产品。

### 3.2 登录

启动软件后进入登录界面，支持 **账号 / 验证码 / 微信** 三种登录方式；登录与授权检查已并入启动动画，登录后直接进入主界面。

- **账号登录**：可使用手机号 + 密码登录，或点击 **注册账号** 创建账号；首次使用需完成相应授权申请。
- **邀请码**：在登录时填写邀请码可获取额外赠送额度（选填）。
- **锁码授权**：点击 **使用锁码授权**，在弹出的 PKPM 授权工具中完成本机授权；具备有效锁码授权时，可通过 **跳过登录** 进入。

## 4. 插件 & 脚本系统

**把一次成功的任务，留成下一次可直接使用的工具。** 在一轮回答末尾点击 **插件 & 脚本**，可将任务制作成插件，或将执行过程中生成的脚本保存到脚本库：

- **插件**：Agent 将流程提炼为带**参数表单**的工具，跨度、截面、材料等作为可填写参数；以后填入参数点击 **运行**，即可按同一逻辑执行。支持「恢复默认参数」，运行后的参数也会记住，方便下次使用。
- **脚本**：收藏本次任务生成的 Python 脚本，可随时查看、编辑、运行。
- **Agent 协同**：插件与脚本既可从对话中创建，也可从左侧页面新建；「让 Agent 修改」用于继续调整，运行失败时还可将参数和错误信息交给 Agent 修复。
- 适用于重复性模型检查、标准化建模流程、批量处理等场景。

### 动态参数：按当前选择填写

插件可根据参数选择显示相关输入项，例如选择矩形截面时填写宽、高，选择圆形截面时填写直径。需要这样的表单时，可以直接让 Agent 配置显示条件。隐藏参数保留之前的取值，但不参与本次输入校验和参数传递；分组也可折叠，减少表单占用。

修改参数后，界面会提示**需要重新运行**，并注明下方仍是上一次结果，便于区分不同方案的计算输出。

### 自定义界面：把工具调整成自己顺手的样子

选中插件后点击 **自定义界面**，可在当前表单上完成调整：

- 按住标题拖动参数或分组，改变顺序与位置；拖动左右边缘调整宽度。
- 点击标签、标题或说明文字直接修改文案。
- 使用撤销、重做查看不同排布，满意后点击**保存**，或点击**取消**放弃本次编辑。

界面编辑用于调整文案和布局；需要新增参数、修改算法或改变显示条件时，使用「让 Agent 修改」。

## 5. 技能、软件连接与本地知识库

### 5.1 Skills 技能

**将经验、方法转化为 skills，相似任务轻松复用。** 系统内置多套专业技能，按用途分为建筑设计、结构设计、通用办公和其他四组。点击左侧 **Skills & MCP**，可查看并管理所有技能。

## 6. 主要功能

### 6.1 操控 PKPM

- **结构模型操作**：创建 / 修改 / 删除梁、柱、墙、板、支撑等构件；定义截面属性与材料等级；操作节点坐标、轴线网格、楼层标高；查询现有模型的几何与属性信息。
- **荷载与工况管理**：施加恒载、活载、风载、地震作用等荷载；定义荷载工况与组合系数；处理吊车、温度、支座沉降等特殊工况。
- **楼层与组装**：创建标准层、定义层高与复制关系、进行楼层组装；修改 / 读取结构总体控制参数（抗震等级、烈度、结构体系等）。
- **计算分析与结果提取**：自动调用 SATWE 计算；提取内力、位移、配筋、应力、周期、振型等结果；读取构件验算结果（轴压比、剪压比、层间位移角等）与计算书文本。
- **多模块联动**：除三维主线模块外，还可连接 **STS 钢结构** 与 **JCCAD 基础**（Beta）模块，在 MCP 接口页开启即可。
- **连接正在运行的 PKPM**：会一并记录其启动参数，计算完成后可按原模块重新打开。

### 6.2 PKPM 图纸审查

通过 `pkpm-checker` 技能，对 DWG 施工图进行识别与校审：

- **识别校审**：把 DWG 施工图交给 Agent，确认抗震构造措施等级、混凝土等级、保护层厚度、楼板厚度等参数后自动识别并审查。
- **查看结果**：审查意见可在对话中以文本查看，也可标注回 AutoCAD 图纸中对应位置。
- **导出报告**：一键导出 Word 审查报告。

### 6.3 操控 SAP2000

通过 `sap2000-link` 技能，使用 Python COM 接口操控 SAP2000：

- **结构建模**：框架、壳、实体、索、钩/隙单元；标准型钢与自定义截面；预应力、桥梁、变截面等特殊单元。
- **荷载与分析**：集中力、分布力、温度、支座沉降、车辆荷载等；线性/非线性静力、模态、反应谱、时程、屈曲、Pushover 等分析类型。
- **结果提取**：节点位移、单元内力、支座反力、模态信息、屈曲系数；钢构件应力比、混凝土配筋结果。
- **典型用途**：处理空间桁架、大跨结构、桥梁等复杂空间结构的补充分析。

### 6.4 操控 ETABS

通过 `ETABS-Link` 技能，使用 Python COM 接口操控 ETABS：

- **结构建模**：点、线、面、实体单元；框架/板/墙截面与材料；楼层标高、轴网、刚性隔板；支座约束、弹簧、阻尼器、隔震/耗能装置等。
- **荷载与工况**：恒载、活载、风载、地震、温度等荷载；多种荷载模式；静力、反应谱、时程、Pushover 等分析工况及组合。
- **分析与结果**：自动运行计算、检查模型完整性；提取内力、位移、层间位移角、模态、反力、应力及设计结果。
- **数据联动**：将模型数据或结果导出到 Excel / Word / PPT，自动生成分析报告或对比表格。

### 6.5 操控 STAAD.Pro

通过 `staadpro-link` 技能，可让智能体直接在 STAAD.Pro 中完成结构建模、计算分析并读取结果：

- **结构建模**：创建节点、杆件、板单元；定义截面属性与材料；布置支座约束。
- **荷载与参数**：施加恒载、活载、风载等荷载；定义荷载工况与组合；设置地震参数。
- **计算与结果**：自动执行分析计算，提取节点位移、构件内力、支座反力等结果。

### 6.6 操控 Abaqus

通过 `abaqus-link` 技能操控 Abaqus / SIMULIA，从建模到看结果全流程可用：

- **建模与修改**：几何、材料、装配、分析步、边界条件、载荷、网格划分与分析设置。
- **提交与结果**：提交作业、查询计算状态、提取并判定结果。
- **按版本匹配 API**：内置 2024 / 2025 / 2026 各版本 API 文档，连接后按实际版本查询，脚本写法与所装版本一致。

启用该技能后，对话中提到 Abaqus、SIMULIA 或 `.cae` / `.inp` / `.odb` 文件时，Agent 可按需求选用相应操作指导。

### 6.7 操控 Tekla Structures

通过 `tekla-link` 技能，实时控制正在运行的 Tekla Structures：

- **自动识别版本**：连接后识别当前运行的 Tekla 版本，匹配 2020 ~ 2026 对应的 Open API。
- **模型操作**：读取当前模型，创建与修改构件，操作节点组件，完成批量化的工程自动化任务。

### 6.8 操控 SAUSG（Beta）

通过 `SSG-link` 技能连接 SAUSG 非线性动力弹塑性分析软件，可对模型进行查看、修改与查询，涉及梁、柱、墙、板等构件、楼层与性能目标。该功能仍在完善中，需在 Skills 与 MCP 接口页手动开启。

### 6.9 操控 Rhino

通过 `Rhino-Link` 技能，使用 Python COM 接口操控 Rhino（犀牛）：

- **几何创建**：NURBS 曲线与曲面（拉伸、旋转、放样、扫掠）、实体与网格布尔运算。
- **建筑与结构建模**：参数化生成建筑外形、幕墙分格、结构构件定位；批量生成梁、柱、支撑等三维实体。
- **编辑与出图**：平移/旋转/缩放/镜像/阵列、几何分析、图层管理、尺寸标注与视图控制。
- **联动应用**：将复杂曲面数据导出供 ETABS / SAP2000 / PKPM 分析，或基于结果生成优化后的建筑形体。

- **自动绘图**：根据数据或指令绘制轴线、梁线、柱截面、剪力墙轮廓、支撑等；添加文字、尺寸标注；插入标准节点详图、柱表、图框等图块。

### 6.13 文档与报告（Word / Excel / PPT / PDF）

将工程资料、计算数据与表达要求交给 Agent，可创建成果文件，也可继续编辑已有文件。2.5.2 对 Word、Excel、PPT 的制作流程进行了全面升级，分别面向**文档格式保留、表格计算正确性和演示文稿交付质量**。

#### PPT：从逐页叙事到版面复核

适用于项目方案、技术汇报、学术答辩、培训课件等材料，可从报告和大纲生成，也可编辑、美化或翻译已有演示文稿。

- **按用途组织内容**：7 类场景指南覆盖工程技术、分析决策、管理汇报、学术研究、教育培训、商业提案与品牌展示。先明确每页要说明什么，再安排结论标题、论据、图表与图片，让整套材料有连贯的叙述和阅读节奏。
- **24 套设计体系**：覆盖学术教学、咨询研究、宣传展示与工作汇报等风格；整套文稿统一字体、配色、字号层级和版面网格，图文页、数据页与章节页采用适合内容的版式。
- **沿用模板与参考风格**：保留公司模板的 Logo、母版、页脚和主题配色；支持替换示例页内容、按参考风格设计，或将图片与 PDF 页面复刻为 PPT。能用文字、图表和形状表达的内容尽量保留可编辑性。
- **复杂内容也能表达清楚**：支持可编辑图表、柱线组合图、表格、公式、流程与结构示意图；可从提供的 Word、PDF、原 PPT 中使用图片，也可使用工程数据绘制分析图。
- **交付前检查版面**：依据 PowerPoint / WPS 的实际排版检查文字超框、遮挡、重叠、越界和空占位符，再导出页面图复核并修正。还会核对文字改动、字体与待补材料，完成后打开成果文件。

描述需求时，可一并给出用途、受众、页数、模板与素材。例如：「用公司模板做 12 页结构方案汇报，重点比较三种方案的用钢量和施工难度，保留主题色与 Logo，数据用图表呈现。」

#### Word：在原文档上完成编辑与排版

- **报告与计算书**：创建技术报告、说明书和计算书，也可在企业模板上填入工程数据，保留样式、编号、分节和页眉页脚。
- **复杂排版**：调整字体、段落、页面、目录、页码、题注与交叉引用；处理合并表格、斜线表头、三线表、列宽、公式和图片。
- **翻译与审阅**：整篇翻译可另存新文件，核对遗漏并调整译文较长的表格；支持批注与修订。修改后可核对内容变化，并借助 Word / WPS 更新目录、检查页面和导出 PDF。

#### Excel：在正在使用的表格中完成计算

- **锁定目标工作簿**：连接用户打开的 Excel / WPS 表格，按指定文件修改数据与公式；打开多个文件时，也围绕目标工作簿操作，减少切错表的干扰。
- **公式驱动结果**：计算列优先写入公式，参数单独放在可修改的单元格中；后续改变输入时，结果由应用重新计算。
- **工程数据处理**：完成批量填表、筛选、分组汇总、比对、数据清洗、数据透视表与图表制作。交付前读回关键数据并检查公式错误。

#### PDF：读取、整理、生成与填表

提取文字、表格与图片，合并、拆分或整理报告页面，生成 PDF 报告，也可填写有交互字段或固定版面的 PDF 表单。扫描资料的文字识别可使用知识库中的 OCR 解析服务。

## 7. 会话与任务管理

### 7.1 交互体验

- **分步推进任务**：先明确对象和目标，再连接软件、查询接口与执行；可以在同一会话中继续补充要求、调整参数或解释结果。
- **需要决策时提问**：关键参数不明确或存在多种操作方案时，Agent 可通过选项向你确认，减少理解偏差。
- **成果与过程分开查看**：思考和工具操作收在「执行过程」中，可随时展开；任务完成后集中阅读回答与成果链接，避免长串执行信息打断阅读。
- **多会话并行**：最多可同时运行三个会话，任务在后台完成或出错时收到系统通知，点击通知可返回对应会话。

**对话分支**：用户消息和回答旁均可点击「从此处创建新聊天」。从用户消息创建时，该消息成为新会话的待编辑草稿；从回答创建时，保留截至该回答的历史，方便继续尝试不同方案。

分支拥有独立的对话记录，并自动添加编号区分，**工作目录沿用源会话**。已有模型和成果文件可继续使用，修改同一文件也会影响其他使用该目录的会话；需要保留不同方案时，应另存模型或成果文件。

### 7.2 工作空间与任务产物

工作空间是当前会话使用的项目目录。显式选择项目文件夹，可把相关任务集中管理；使用默认工作空间时，软件会为任务创建目录，按日期与任务标题命名，便于找到成果。

点击会话右上角的**任务产物**按钮，可查看工作空间中的文件：

- 浏览文件夹与文件，预览文本、代码、Markdown 和图片；其他格式可用系统默认应用打开。
- 切换全屏查看，便于阅读长文或检查生成的图像；图片支持放大查看。
- 将文件拖入对话框，或右键选择「添加到聊天」，继续修改、分析或整理成果；也可复制路径、打开文件及所在目录。

### 7.3 权限控制

在输入框下方选择 Ask / Auto / Full，决定代码与命令执行前如何审批：

- **请求批准（Ask）**：Python 脚本和命令执行前均请求批准，适合需要逐步检查操作的任务；审批时可允许本次、在当前会话中始终允许该工具，或拒绝执行。
- **替我审批（Auto）**：Python 脚本与通过内置检查的命令直接执行；被识别为可能有风险的命令请求批准，适合日常任务。
- **完全访问（Full）**：Python 脚本和命令不经过工具执行审批，适合目标与操作范围明确的任务。

权限模式控制执行前的审批方式；任务中需要你决定的专业参数或方案，仍可单独询问。涉及已有模型或成果文件时，建议先明确改动范围与是否另存。
