# PKPM Agent 用户手册
## 1. 基本介绍
PKPM 结构设计智能体是一款基于大语言模型的设计辅助工具。通过自然语言交互的方式，可以实现：

- 🏗️ **结构模型创建与修改**
- 📊 **荷载自动布置**
- 📈 **计算结果查询与可视化**
- 📐 **CAD 自动绘图**

## 二、使用设置

### 2.1 软件环境

- 已安装 64 位的 PKPM 结构设计软件（PKPM2026R1.0-64）
- 已安装 CAD 软件（用于绘图功能，支持 AutoCAD 2010 及以上版本）
- 操作系统：Windows 10/11 64 位系统
- 网络环境：需保持网络连接（用于大语言模型调用）

### 2.2 工具启动

打开 PKPM 软件并进入目标工程后，在构件菜单栏中点击【PKPM Agent 尝鲜版】，系统会进入到相关操作界面，当前界面可以自行调整大小，按照用户的相关需求可自行调整。

![工具启动界面](HelpImage/启动.png)

### 2.3 模型选择

在 Agent 面板中点击 "管理" 按钮，从下拉菜单中选择所需大语言模型：

- 优先选择 "ChatGLM 智谱清言"

若是需要启动对应的大模型能力，需要进行获取相关大模型进行服务。目前系统支持多种模型接入。同时也支持用户自行进行更强力的模型。满足用用户的需求。

整体的接入过程可以分为三步：

1. 进入到API获取界面
2. 选择厂商的模型服务，获取token数量
3. 获取APIkey

下面对整个过程进行说明。（涉及模型厂商较多，本文仅介绍总体做法，各家厂商总体思路一致，更多详细内容，可以查看对应官方文档）

关键点在于获取三个参数：**模型ID**、**对应的API地址**、**相关账户的APIkey**。

#### 2.4.1 进入到API获取界面

1. 点击模型下方的拉取按钮选择右侧的按钮
2. 点击即可弹出相关对话框，点击获取API密钥可以跳转到模型服务能力提供方
3. 首次登录需要注册账号，进入后可以按照相关操作指引获取API秘钥，并输入到原API位置。系统默认为大模型官方网站，也可以接入硅基流动等第三方服务商

#### 2.4.2 选择厂商的模型服务

关于模型ID: 不同的厂商其开发的大模型能力各有区别，各家均发布了较多的模型。即使是同一个厂商，其内部有较多的模型型号，提供不同的服务。如GLM-4.5、GLM-4.5x等，在对于模型的选择上,建议如下：

- 对于初步使用Agent的用户，建议以默认的模型ID进行应用，因为提供的各个厂商的默认模型已经经过内部严格评估，其任务执行能力，推理能力及稳定性都进行了验证，能够支撑其发挥对应功能。若需要更新，调整模型，建议向上兼容，即选取在此模型系列上更为强劲的模型，效果与体验会更好些。

- 若为深度体验用户尝试自行选择模型的版本，有此需求可联系技术支持侧同事进行专项询问，了解。

进入到模型API提供页面中，可以根据需求选择对应的模型型号，包括token流量包的规格。进行购买和使用。按照经验预估，每次问答token消耗量在7k~1w左右，具体消耗情况需要结合任务的复杂程度。可以根据用时进行评估购买。

#### 2.4.3 获取对应模型的地址

对应api的请求地址在各模型厂商官方说明手册都会体现，在模型ID不调整的情况下，地址无需调整，建议都是默认。若需要查找，模型API地址所在位置一般为文档（手册）—首次调用API介绍说明—API请求地址，若未能获取也可以询问技术支持相关同事。

#### 2.4.4 获取API key

主流大语言模型（千问、Kimi、智谱清言、DeepSeek）的 API 密钥获取均遵循相似流程：需先访问对应官方平台（阿里云灵积平台、Moonshot AI 官网、智谱 AI 开放平台、DeepSeek 开放平台），完成账号注册与必要的身份验证后，登录开发者控制台或 API 管理页面，在密钥管理相关模块（如 "API 密钥管理"、"Access Token" 或 "密钥管理"）中创建并获取 API 密钥。

获取过程中需注意：

- 各平台均要求开通对应模型服务并确保账户状态正常
- 密钥属于敏感信息，生成后需立即妥善保存（部分平台密钥仅显示一次）
- 应遵循最小权限原则，为不同环境配置不同密钥，并定期轮换
- 如遇泄露需立即在平台吊销并重生成，同时注意各平台的调用额度与计费标准

## 三、功能介绍

### 3.1 整体功能介绍

#### 3.1.1 界面

1. **历史问答栏**：点击此处，可以查看当前Agent的历史操作记录，再次点击后可进行收回。支持点击历史记录进行查看。

2. **预设提示词**：方便用户快速的进行应用一些场景，选择后即可进行任务。

3. **输入对话框**：用户可在此处输入相关自然语言命令，驱动agent进行相关任务。

其中左侧为模型选择功能栏，上文已经介绍，此处不做赘述。

**【管理】按键**用来形成对于相关工具进行开关，可以根据当前命令执行涉及的功能情况进行筛选，动态调整开关相关功能。需要注意的事：目前功能的开关带有记忆功能，启动新的模型后仍然会保留相关设置情况，执行不同的工作需要注意相关功能的开关状况，以保证相关生成效果。

4. **意见反馈与收集列表**：点击后可进入到用户意见收集页面。

#### 3.1.2 相关功能

1. 支持对提示词进行调整，编辑。可在提示内容中直接对内容进行修改，同时保留上一次提示词下面的问题回复。

2. 每次问答完成后会在问答的最下方对本次消耗的Token进行统计显示。

系统目前内置了6大类近百余种工具，涵盖建模、截面编辑、荷载添加、构件结果、指标结果、CAD绘制等涉及结构设计师常用近90%功能。可以基于相关能力根据需求自主发起相关指令。以下是相关场景示意说明。

> **注意**：使用相关功能需要打开相关工具，如果不打开，则执行的效果有可能不符合预期。

### 3.2.1 结构模型新建 / 提取 / 修改

#### 功能概述

通过自然语言指令让智能体自动操纵 PKPM 软件，完成模型构件创建、连接关系调整、参数修改等任务，支持梁柱、标准层等核心构件操作。

#### 示例说明

**任务**：在选中的柱子顶部连接上主梁，xy 两个方向都形成框架

**步骤**：

1. 在模型中用鼠标点选目标柱子（选中后柱子呈白色高亮）
2. 在 Agent 输入框中输入指令："在选中的柱子顶部连接上主梁，xy 两个方向都形成框架"
3. 点击 "提交"，工具将自动计算主梁尺寸、定位，并在柱子顶部 xy 方向生成框架梁

### 3.2.2 荷载布置

#### 功能概述

支持读取 Excel 格式的上游提资数据（如恒载、活载数值及坐标），自动完成楼层、节点的荷载布置，减少手动输入错误。

### 3.2.3 自然语言查询计算结果

#### 功能概述

通过自然语言指令查询结构计算结果（如轴压比、位移角等），并自动生成直方图、曲线等可视化图表，无需手动导出数据后二次处理。

#### 示例说明

**任务 1**：获取选中柱子的轴压比，绘制直方图

**步骤**：

1. 在计算完成后的模型中，用鼠标选中需查询的柱子（可框选多个）
2. 输入指令："获取选中柱子的轴压比，绘制直方图"，点击 "提交"
3. 工具生成直方图，横轴为柱子编号，纵轴为轴压比值，可直观对比各柱子指标

#### 注意事项

- 需在计算完成后使用该功能（未计算时将提示 "无有效计算结果"）
- 指令需明确数据维度（如 "选中柱子""全楼楼层"），避免模糊表述（如 "查轴压比"）

### 3.2.4 操纵 CAD 自动绘图

#### 功能概述

实现 PKPM 与 CAD 的数据双向流转，通过指令将 PKPM 中的构件（如梁、柱）自动导出至 CAD 并完成截面尺寸标注，减少手动绘图工作量。

## 四、Q&A

### 4.1 指令提交后无响应

- 检查网络连接是否正常（大语言模型需联网调用）
- 确认指令是否清晰（避免歧义表述，如 "画梁" 需明确位置和类型）
- 重启 PKPM 软件并重新激活 Agent 工具

### 4.2 操作结果与预期不符

- 核对指令是否遗漏关键信息（如未说明 "xy 方向""楼层范围"）
- 检查模型状态
- 在 Agent 面板点击 "许愿池 & 点我吐槽" 反馈问题，附上指令和截图
